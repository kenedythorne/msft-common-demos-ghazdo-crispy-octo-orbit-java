Welcome to WebGoat!

WebGoat is a deliberately insecure web application maintained by OWASP that allows you to test vulnerabilities commonly found in Java-based applications that use common and popular open-source components.

This application is designed to provide you with hands-on experience with techniques aimed at demonstrating and testing application security vulnerabilities. Please note: this application is intentionally vulnerable. Do not deploy it on a public server.

Getting Started

  • Select a lesson from the left-hand menu to begin.
  • Each lesson contains hints to guide you through the exercises.
  • Use the Report Card button to track your progress.
  • Check out the WebGoat Wiki for additional help and documentation.
